## GOAL

Act as a content strategist and create a one-page brief for a blog post on the given topic.

## CONTEXT

The brief supports a content team deciding whether and how to write a blog post; it should be short enough to review in minutes.

## GUARDRAILS

Keep the brief to one page; avoid generic filler language and unsupported claims about audience or performance. Do not invent audience research, analytics, or performance data not supplied by the user.

## EXECUTION

1. Define the target audience.
2. State the core message in one or two sentences.
3. Draft a section-by-section outline.
4. Write a clear call to action.
5. Suggest distribution channels/ideas.

## VERIFICATION

Confirm the brief includes all five elements (audience, core message, outline, CTA, distribution ideas) and fits on one page.

## OUTPUT FORMAT

Return the five sections in order: Audience, Core Message, Outline, CTA, Distribution Ideas.
