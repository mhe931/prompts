# Content guide

## Supported files
- `.md`
- `.txt`

## Directory conventions

`prompts/<category>/<file>.md|txt`

Default categories: coding, writing, research, presentations, other.

## Metadata (optional)
Use front matter:

```md
---
title: Better display title
description: Short summary
---
```

## Operations
- Add: place file and regenerate manifest.
- Rename/move: change file path and regenerate manifest.
- Remove: delete file and regenerate manifest.
